# Інструкції для запуску класифікаційних моделей

## Опис завдання

Файл `classification_models.py` реалізує повний цикл машинного навчання для класифікації погодних даних:

### Цільові змінні (на основі бізнес-питань):

1. **Екстремальна спека** (бінарна): Чи буде температура ≥40°C?
2. **Штормові умови** (бінарна): Чи будуть опади >10мм + вітер >15м/с?
3. **Категорії температури** (мультикласова): Холодно/Прохолодно/Тепло/Спекотно
4. **Рівень опадів** (мультикласова): Без опадів/Легкі/Помірні/Сильні

### Моделі класифікації:

**Для бінарної класифікації:**
- Логістична регресія
- Random Forest
- Gradient Boosted Trees
- Decision Tree

**Для мультикласової класифікації:**
- Логістична регресія (multinomial)
- Random Forest
- Decision Tree

### Метрики оцінки:

**Бінарна класифікація:**
- Accuracy, Precision, Recall, F1-score
- AUC-ROC, AUC-PR

**Мультикласова класифікація:**
- Accuracy, Precision, Recall, F1-score (weighted)

## Структура виконання

1. **Підготовка даних**:
   - Створення цільових змінних
   - Додавання ознак взаємодії
   - Сезонні ознаки

2. **Обробка ознак**:
   - VectorAssembler для об'єднання ознак
   - StandardScaler для нормалізації

3. **Навчання моделей**:
   - Розділення train/test (70/30)
   - Навчання 3-4 моделей для кожної задачі
   - Оцінка якості

4. **Порівняння результатів**:
   - Таблиці з метриками для всіх моделей
   - Рекомендації щодо найкращих моделей

5. **Налаштування гіперпараметрів**:
   - Cross-validation для Random Forest
   - Пошук оптимальних параметрів

## Інтерпретація результатів

### Для бізнес-рішень:

1. **Екстремальна спека**: Допомагає планувати графіки персоналу
2. **Штормові умови**: Планування реагування на надзвичайні ситуації
3. **Категорії температури**: Оптимізація енергоспоживання
4. **Рівень опадів**: Планування логістики та постачання

### Вибір моделі:

- **Random Forest**: Зазвичай найкращий баланс точності та інтерпретованості
- **Gradient Boosting**: Найвища точність, але довше навчання
- **Логістична регресія**: Швидка та інтерпретована, але може бути менш точною
- **Decision Tree**: Найбільш інтерпретована, але схильна до перенавчання

3. Для великих наборів даних збільште `spark.driver.memory` та `spark.executor.memory`
